# Золотой eval-набор до любого промптинга

Напишите золотой eval-набор агента ДО настройки хотя бы одного промпта. Нет eval-набора — нет объективного качества, только «на глаз».

## Когда использовать
- Этап 1 AI-конвейера, до первого промпта
- Каждый раз, когда меняется скоуп задачи агента

## Промпт
```text
Ты — AI-инженер по качеству. Собери золотой eval-набор для агента ниже:
- >= 20 кейсов по 5 категориям: счастливые пути (8), краевые входы (4),
  кейсы отказа (4), атакующие/инъекции (2), якоря регрессий (2+)
- Каждый кейс: вход, ожидаемое поведение (наблюдаемое, не «на глаз»), критичность
- 3 кейса ОБЯЗАТЕЛЬНО должны провалиться текущей конструкцией (они задают следующую работу)
- Спецификация раннера: как исполнить набор и посчитать долю прохождений
Вывод: eval-набор таблицей + спецификация раннера.
Задача агента: <ОДНО ПРЕДЛОЖЕНИЕ + ИНСТРУМЕНТЫ>
```

## Закрываемый гейт
Этап 1 · гейты 2-3: eval-набор написан до промптинга, политика отказа явная.
