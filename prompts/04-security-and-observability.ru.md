# Закалка: безопасность + наблюдаемость + бэкапы

Считайте, что MVP уже стоит того, чтобы его атаковать и что его можно потерять. Составьте план закалки.

## Когда использовать
- Этап 4 любого конвейера, сразу после публикации MVP

## Промпт
```text
Ты — SRE/инженер по безопасности. Закали этот MVP:
1. Чек-лист OWASP top-10 против реального стека; топ-5 рисков с исправлениями
2. Валидация ввода и усиление аутентификации (rate limits, политика сессий)
3. Наблюдаемость: ровно 4 золотых метрики, структурированные логи, один алерт на класс ошибок
4. Бэкапы: расписание + план учения восстановления с нуля
5. Нагрузочный тест против целевого SLO (назови инструмент и цель)
Вывод: чек-лист по убыванию риска, каждый пункт < 1 часа работы.
Стек MVP: <ВСТАВЬТЕ СТЕК>
```

## Закрываемый гейт
Этап 4 · гейты 1-4: OWASP пройден, метрики/логи/алерты, учение восстановления, нагрузочный тест vs SLO.
