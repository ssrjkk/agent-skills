▸ Stage 1. Assertion-Evidence Narrative & Action Title ScanЭтап 1. Сторителлинг по модели Assertion-Evidence и скелет заголовков live

  • Writing declarative Action Titles ('Cilium eBPF Cut Latency by 38%') so reading only headlines conveys the full pitch
  • Enforcing strict slide density: 1 primary visual proof (diagram, chart, or 12-line code block) + at most 3 concise bullets
  • Формулировка тезисных заголовков с цифрой и выводом, чтобы чтение одних заголовков складывалось в законченный питч
  • Жесткий контроль плотности слайда: ровно 1 визуальное доказательство (схема, график или код) и не более 3 коротких тезисов

▸ Stage 2. Interactive 16:9 HTML/CSS/JS Slide Decks as CodeЭтап 2. Верстка интерактивных презентаций 16:9 на HTML/CSS/JS live

  • Building zero-dependency single-file HTML slide decks with clamp() typography and keyboard/touch navigation
  • Embedding live copyable code blocks, vector SVG diagrams, and @media print rules for landscape PDF export
  • Сборка автономных HTML-презентаций без внешних зависимостей с адаптивной типографикой clamp() и управлением с клавиатуры
  • Встраивание интерактивных блоков кода, векторных SVG-схем и правил @media print для чистой выгрузки в PDF
