▸ Stage 1. Git Hygiene, Atomic Commits & High-Signal Code ReviewЭтап 1. Гигиена Git, атомарные коммиты и инженерное код-ревью live

  • Trunk-based development, interactive rebase, git bisect bug hunting, Conventional Commits, and automated pre-commit hooks
  • Conducting high-signal code reviews: checking concurrency invariants, security boundaries, failure handling, and test coverage
  • Разработка от мастер-ветки (Trunk-Based), интерактивный ребейз, поиск регрессий через git bisect и хуки pre-commit
  • Проведение глубокого код-ревью: проверка инвариантов конкурентности, безопасности, обработки ошибок и полноты тестов

▸ Stage 2. Clean Architecture, Domain Boundaries & TDDЭтап 2. Чистая архитектура (Ports & Adapters) и дисциплина TDD live

  • Decoupling domain logic from frameworks and databases using Hexagonal / Clean Architecture (Ports and Adapters)
  • Red-Green-Refactor TDD loops, contract testing, property-based testing (Hypothesis), and deterministic dependency injection
  • Отделение бизнес-логики от фреймворков и баз данных по принципам Чистой и Гексагональной архитектуры (Ports & Adapters)
  • Цикл разработки через тестирование (TDD Red-Green-Refactor), контрактные тесты и генеративное тестирование (Hypothesis)

▸ Stage 3. Vibe-Coding GitHub Ecosystem, MCP & Editor Rules (Map 21)Этап 3. Экосистема вайбкодинга на GitHub, MCP-серверы и правила ИИ (Карта 21) live

  • Mastering core internals by rebuilding systems from scratch with codecrafters-io/build-your-own-x (~556k stars)
  • Rapid prototyping and pet-project data integration using free endpoints from public-apis/public-apis (~492k stars)
  • Connecting coding agents to Postgres, Gmail, Sheets, and browsers via Model Context Protocol (punkpeye/awesome-mcp-servers)
  • Locking stack conventions and anti-slop guardrails in Cursor, Claude Code, and OpenCode via PatrickJS/awesome-cursorrules
  • Глубокое понимание технологий через сборку собственных реализаций по гайдам codecrafters-io/build-your-own-x
  • Быстрая сборка живых продуктов с подключением внешних данных из каталога бесплатных API public-apis/public-apis
  • Подключение ИИ-агентов к базам данных, почте, таблицам и браузеру по стандарту MCP (punkpeye/awesome-mcp-servers)
  • Фиксация архитектурных правил проекта для ИИ-редакторов через файлы .cursor/rules, CLAUDE.md и AGENTS.md

▸ Stage 4. Highload System Design (10,000+ RPS & Multi-AZ) (Map 11)Этап 4. Проектирование высоконагруженных систем 10 000+ RPS (Карта 11) live

  • Back-of-the-envelope capacity planning: estimating read/write RPS, network bandwidth, RAM cache sizing, and disk IOPS
  • Eliminating Single Points of Failure (SPOF) across CDN/WAF, L4/L7 balancers, 3-AZ Kubernetes, Redis, Kafka, and HA Postgres
  • Distributed reliability patterns: idempotency keys, circuit breakers, exponential backoff with jitter, and transactional Outbox
  • Инженерный расчет нагрузки на салфетке: оценка RPS чтения/записи, полосы сети, объема RAM под кэш и IOPS дисков
  • Проектирование без единых точек отказа (Zero SPOF): мульти-зональный K8s, кэш Redis, буферизация пиков в Kafka и кворумная БД
  • Паттерны надежности распределенных систем: ключи идемпотентности, Circuit Breaker, ретраи с jitter и паттерн Outbox

▸ Stage 5. Production Pet-Project & Open-Source Packaging (Maps 07, 23)Этап 5. Сборка эталонного продакшн пет-проекта и упаковка Open Source (Карты 07, 23) live
