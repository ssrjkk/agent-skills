## Сознательно НЕ делаю (и почему)
- **Сжатие index.html (356K)** — Pages отдаёт gzip; реального UX-эффекта не измерено, YAGNI. Вернуться при росте >1МБ.
- **Локальный playwright-прогон** — chromium в CI; локально верифицируется встроенным браузером при необходимости.
- **Поднятие coverage 93% → 95%+** — гейт 90% выполняет свою роль; дожим проверок лабы (bash) не окупается.
- **Серверный RU-рендер страниц скиллов** — v4.3, требует изменения генератора; сейчас клиентское переключение достаточно.
- **Удаление `ROADMAP_TRACKS` seed** — это graceful-degradation fallback для тестов и битого каталога, не мёртвый код.
- **Обновление `updated` дат 100 старых скиллов** — без реального изменения контента это ложь метрикам (freshness 83% честная).

## Что усиливает идею
Всё из очереди укрепляет «проверяемость» (гейты) и «обучаемость» (портал) — ядро проекта. Ни один пункт не ведёт в другой продукт.
