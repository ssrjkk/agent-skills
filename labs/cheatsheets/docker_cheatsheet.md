# Шпаргалка: Команды Docker

## Управление контейнерами и образами
- `docker ps -a` — список всех контейнеров (включая остановленные).
- `docker logs -f --tail=100 <container_id>` — просмотр логов контейнера в реальном времени.
- `docker exec -it <container_id> /bin/sh` — подключение внутри запущенного контейнера.
- `docker system prune -a --volumes` — полная очистка неиспользуемых образов, контейнеров, сетей и томов.
- `docker inspect <container_id>` — детальная информация о конфигурации контейнера в формате JSON.

## Сборка и отладка
- `docker buildx build --platform linux/amd64,linux/arm64 -t myapp:latest .` — мультиархитектурная сборка.
- `docker stats` — мониторинг потребления CPU, памяти и сети запущенными контейнерами.
