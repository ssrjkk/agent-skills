▸ Stage 1. Design Specifications in Markdown & Diagrams as CodeЭтап 1. Дизайн-спецификации в Markdown (Design.md) и схемы кодом live

  • Structuring unambiguous UI/UX requirements, user flows, and state matrices in DESIGN.md before generating code
  • Rendering architecture, sequence, and C4 system diagrams as version-controlled Mermaid, D2, and PlantUML code
  • Фиксация структуры экранов, пользовательских сценариев и матрицы состояний в файле DESIGN.md до начала генерации кода
  • Проектирование архитектурных, сетевых и продуктовых схем кодом через Mermaid, D2 и PlantUML с чистыми диффами в Git

▸ Stage 2. Token-Driven Design Systems & Accessibility (WCAG AA/AAA)Этап 2. Токенизированные дизайн-системы и доступность WCAG AA/AAA live

  • Primitive vs semantic CSS tokens (--bg-canvas, --bg-surface, --text-primary), 8px spatial grids, and concentric border radii
  • Fluid clamp() typography, Cyrillic/Latin font pairing, WCAG >= 4.5:1 contrast verification, and :focus-visible rings
  • Разделение примитивных и семантических CSS-токенов, модульная сетка отступов 4px/8px и формула вложенных радиусов
  • Плавная типографика на clamp(), подбор шрифтов с кириллицей, проверка контраста WCAG >= 4.5:1 и видимый фокус с клавиатуры

▸ Stage 3. Intentional Art Direction & Anti-Template TasteЭтап 3. Арт-дирекшн, визуальный вкус и уход от ИИ-шаблонов live

  • Replacing generic Indigo/Purple AI templates with the 60-30-10 color rule and domain-grounded visual archetypes
  • Designing hero focal artifacts (interactive terminals, live product stages, and real metrics) instead of decorative filler
  • Отказ от шаблонных фиолетовых градиентов в пользу правила палитры 60–30–10 и предметных визуальных архетипов
  • Построение первого экрана вокруг живого продуктового артефакта (интерактивный терминал, витрина или граф) вместо пустых картинок

▸ Stage 4. Optical UI Polish, Zero-CLS & High-Converting LandingsЭтап 4. Оптическая шлифовка UI, геометрия Zero-CLS и конверсионные лендинги live

  • Conversion-driven landing page architecture: batched intake, single primary CTA above the fold, proof strips, and objection FAQs
  • Optical alignment audit: equal-height grid cards, tabular-nums counters, text-wrap: balance headings, and zero layout shift
  • Архитектура конверсионного лендинга: один главный CTA на первом экране, конкретные цифры выгод, блок доказательств и разбор возражений
  • Оптическая полировка: выравнивание карточек в сетке, табличные цифры tabular-nums, сбалансированные заголовки и нулевой CLS
