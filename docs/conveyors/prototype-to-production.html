# Idea → One-page Spec

Turn the idea below into a one-page spec a single engineer can start tomorrow.

When to use

  • Stage 1 of any conveyor, before writing a single line of code
  • Any time the scope of an ongoing project quietly grows

Prompt

You are a product engineer. Convert the idea below into a one-page spec.
Rules:
- Cut scope aggressively: exactly ONE runnable vertical slice.
- No feature without a measurable success metric. Unmeasurable wishes go to Non-goals.
- The slice must have a Definition of Done checkable in one working day.
- Output exactly these sections, nothing else:
  1. Problem (2 sentences, who hurts and why)
  2. Target user (one persona)
  3. Success metric (one number with a deadline)
  4. The one slice (steps a user takes, first to last)
  5. Non-goals (at least 3 explicit rejections)
  6. Definition of done (checkbox list)

Idea: <PASTE YOUR IDEA>

# Идея → Спецификация на одну страницу

Превратите идею ниже в спецификацию на одну страницу, которую один инженер может начать делать завтра.

Когда использовать

  • Этап 1 любого конвейера, до первой строки кода
  • Каждый раз, когда скоуп текущего проекта тихо разрастается

Промпт

Ты — продуктовый инженер. Преобразуй идею ниже в спецификацию на одну страницу.
Правила:
- Режь скоуп агрессивно: ровно ОДИН выполнимый вертикальный срез.
- Ни одной фичи без измеримой метрики успеха. Неизмеряемые пожелания — в «Не делаем».
- У среза есть Definition of Done, проверяемое за один рабочий день.
- Выводи ровно эти разделы, ничего больше:
  1. Проблема (2 предложения: кому больно и почему)
  2. Целевой пользователь (одна персона)
  3. Метрика успеха (одно число с дедлайном)
  4. Один срез (шаги пользователя от первого до последнего)
  5. Не делаем (минимум 3 явных отказа)
  6. Definition of done (чек-лист)

Идея: <ВСТАВЬТЕ СВОЮ ИДЕЮ>
