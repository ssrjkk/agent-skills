# Шпаргалка: Команды Linux для DevOps

## Диагностика процессов и ресурсов
- `htop` / `top` — интерактивный мониторинг процессов.
- `ps aux --sort=-%mem` — список процессов, отсортированных по потреблению памяти.
- `uptime` — проверка времени работы системы и Load Average.
- `free -m` — использование оперативной памяти и подкачки в мегабайтах.
- `vmstat 1` — ежесекундная статистика по CPU, памяти и I/O.
- `iostat -xz 1` — детальная диагностика дисковых устройств и очередей I/O.
- `dmesg -T | grep -i oom` — поиск сработавших OOM Killer в системном логе.

## Сетевая диагностика
- `ss -tulpan` — просмотр всех активных сетевых портов и удерживающих их процессов.
- `ip -br a` — краткий вывод сетевых интерфейсов и IP-адресов.
- `dig +trace domain.com` — детальный трассировочный запрос DNS-записи.
- `nc -zv host 80` — проверка доступности TCP-порта.
- `tcpdump -i eth0 -nn -s0 -w capture.pcap port 443` — захват сетевого дампа трафика.

## Файлы и диски
- `df -h` — свободное место на смонтированных файловых системах.
- `du -sh /var/log/* | sort -hr` — поиск самых тяжелых директорий и файлов.
- `lsof +D /var/log/` — список открытых файлов в директории.
- `find /var/log -type f -mtime +7 -delete` — удаление файлов старше 7 дней.
