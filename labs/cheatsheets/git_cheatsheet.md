# Шпаргалка: Продвинутый Git

- `git log --oneline --graph --decorate --all` — красивое визуальное отображение дерева веток и коммитов.
- `git rebase -i HEAD~5` — интерактивный ребаз последних 5 коммитов (сквош, переупорядочивание, правка).
- `git stash push -m "work in progress" && git stash pop` — временное сохранение незакоммиченных изменений и их восстановление.
- `git reflog` — история всех перемещений HEAD (позволяет восстановить удаленные ветки или неудачный rebase).
- `git branch --merged | grep -v '\*' | xargs git del` — удаление локальных веток, которые уже были слиты в main.
