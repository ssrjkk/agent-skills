▸ Stage 1. Linux Kernel Internals, eBPF & Networking (Map 01)Этап 1. Внутреннее устройство ядра Linux, eBPF и сети (Карта 01) live

  • Process scheduler (CFS), states R/S/D (uninterruptible I/O sleep) and Z (zombies), PID 1 signal handling with tini
  • Namespaces (pid, net, mnt, user) and cgroups v2 (memory.max, cpu.max, OOM Killer scoring)
  • Filesystems, inodes (df -i), and fixing 100% disk usage from deleted open files via lsof +L1 and /proc/<PID>/fd
  • USE/RED triage in 60 seconds: uptime, vmstat 1, iostat -xz 1, ss -tulpan, and eBPF kernel tracing
  • TCP/IP handshake, TLS 1.3, DNS troubleshooting (dig +trace), nf_conntrack tuning, and hardened Nginx/Envoy
  • Планировщик CFS, статусы процессов R/S/D (ожидание диска/NFS) и Z (зомби), обработка сигналов PID 1 через tini
  • Изоляция namespaces (pid, net, mnt, user) и лимиты cgroups v2 (memory.max, cpu.max, работа OOM Killer)
  • Файловые системы, иноды (df -i) и очистка удаленных открытых файлов через lsof +L1 без рестарта процесса
  • Методологии USE и RED за 60 секунд: uptime, vmstat 1, iostat -xz 1, ss -tulpan и трассировка ядра eBPF
  • Стек TCP/IP, TLS 1.3, отладка DNS (dig +trace), тюнинг таблицы nf_conntrack и боевой Nginx/Envoy

  • Программируемые пайплайны на Go через Dagger SDK для полной идентичности локального и CI-запуска

▸ Stage 4. Kubernetes Architecture, Cilium eBPF & Autoscaling (Map 04)Этап 4. Архитектура Kubernetes, Cilium eBPF и автоскейлинг (Карта 04) live

  • Устройство Control Plane: kube-apiserver, кворум etcd Raft и восстановление снапшотов, планировщик и kubelet
  • Надежность подов: пробы startup/liveness/readiness, классы QoS, бюджеты PDB и распределение по зонам (AZ)
  • Сетевой стек Cilium eBPF вместо iptables, фильтрация на уровне L7 и переход с Ingress на Gateway API (HTTPRoute)
  • Масштабирование подов по длине очереди через KEDA и быстрый заказ Spot-узлов через Karpenter

▸ Stage 7. Bare-Metal Kubernetes: Talos Linux, Cilium BGP & Storage (Map 17)Этап 7. Bare-Metal Kubernetes: Talos Linux, Cilium BGP и СХД (Карта 17) live

  • Immutable API-driven Talos Linux: zero SSH, zero shell, declarative upgrades and recovery via mTLS talosctl gRPC API
  • Cilium BGP Control Plane on bare metal: announcing LoadBalancer VIPs via ECMP to Top-of-Rack switches
  • Bare-metal CSI architecture: distributed Rook-Ceph (RWO/RWX/S3) vs local NVMe TopoLVM for replicated databases
  • Неизменяемая ОС Talos Linux без SSH и пакета утилит: управление и обновление узлов исключительно через mTLS gRPC API talosctl
  • Анонсы внешних IP для Service: LoadBalancer по протоколу BGP (ECMP) в Cilium напрямую на коммутаторы стойки (ToR)
  • Выбор СХД на голом железе: распределенный Rook-Ceph для общих томов против локальных NVMe (TopoLVM) для кластерных БД
