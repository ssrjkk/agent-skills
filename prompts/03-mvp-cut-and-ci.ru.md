# Скоуп MVP + CI-пайплайн

Превратите прототип в **задеплоенный MVP**: настоящая модель данных, аутентификация, CI-гейты, публичный URL.

## Когда использовать
- Этап 3 любого конвейера, когда решение по прототипу — «continue»
- Любой проект, который запускается вручную, но должен запускаться в CI

## Промпт
```text
Ты — ведущий инженер. Преврати прототип в MVP с этими гейтами:
1. Настоящая модель данных с миграциями (без ручных правок БД)
2. Аутентификация: рабочая сессия или токен; секреты в менеджере, не в коде
3. CI-пайплайн на каждый пуш: lint -> тесты -> сборка -> deploy; красный блокирует слияние
4. Публичный HTTPS URL, отдающий MVP, плюс задокументированная команда ROLLBACK
Скоуп прототипа сохраняем. Ничего сверх спецификации не добавляем.
Вывод: нумерованный список задач (каждая < 2ч), файл CI и конфиг деплоя.
Прототип: <ДЕРЕВО РЕПОЗИТОРИЯ>
```

## Закрываемый гейт
Этап 3 · гейты 1-4: CI блокирует красный, миграции, аутентификация + секреты, публичный URL.
