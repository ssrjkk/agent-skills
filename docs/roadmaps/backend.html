▸ Part I. Foundation (months 1–4)Часть I. Фундамент (месяцы 1–4) live

  • Environment, terminal, Git: branches, pull requests, clean history
  • Python core: types, containers, comprehensions, error handling
  • OOP and idiomatic Python: dataclasses, protocols, typing
  • Testing basics: pytest fixtures and parametrization
  • Algorithms: arrays, hash tables, two pointers, complexity analysis
  • Project #1: CLI application with tests and CI
  • Окружение, терминал, Git: ветки, pull request, чистая история
  • Основы Python: типы, коллекции, включения, обработка ошибок
  • ООП и идиоматичный Python: dataclasses, протоколы, типизация
  • Начало тестов: фикстуры и параметризация в pytest
  • Алгоритмы: массивы, хеш-таблицы, два указателя, оценка сложности
  • Проект №1: CLI-приложение с тестами и CI

▸ Part II. Backend developer (months 4–9)Часть II. Бэкенд-разработчик (месяцы 4–9) live

  • Network, HTTP, Linux: methods, headers, auth, curl, DevTools
  • SQL and PostgreSQL: schema design, joins, transactions, indexes
  • Web frameworks: FastAPI and Django, API design crafts
  • Docker, CI/CD, deploy: multi-stage images, pipelines, readiness
  • Project #2: deployed REST API with authorization and PostgreSQL
  • Outcome: ready to respond to junior openings
  • Сеть, HTTP, Linux: методы, заголовки, аутентификация, curl, DevTools
  • SQL и PostgreSQL: проектирование схемы, соединения, транзакции, индексы
  • Веб-фреймворки: FastAPI и Django, дизайн API
  • Docker, CI/CD, деплой: multi-stage образы, пайплайны, готовность
  • Проект №2: задеплоенное REST API с авторизацией и PostgreSQL
  • Результат: можно откликаться на junior-вакансии

▸ Part III. Professional engineering (months 9–15)Часть III. Профессиональная инженерия (месяцы 9–15) live

  • Python internals: typing, concurrency, performance profiling
  • Architecture: ports and adapters, layered design, review culture
  • Caches, queues, events: Redis, broker patterns, idempotency, outbox
  • Middle-level testing: integration, contract-like suites, quality gates
  • Observability and operations: RED metrics, logs, incidents, postmortems
  • Backend security: OWASP, secrets management, rate limiting
  • System design: capacity, consistency, graceful degradation
  • Projects #3–4 plus capstone system
  • Python изнутри: типизация, конкурентность, профилирование производительности
  • Архитектура: порты и адаптеры, слоистый дизайн, культура ревью
  • Кэши, очереди, события: Redis, паттерны брокеров, идемпотентность, outbox
  • Тестирование уровня middle: интеграционные наборы, quality gates
  • Наблюдаемость и эксплуатация: RED-метрики, логи, инциденты, постмортемы
  • Безопасность бэкенда: OWASP, секреты, ограничение частоты запросов
  • System Design: ёмкость, согласованность, деградация без падения
  • Проекты №3–4 и капстоун-система

▸ Part IV. Work and growth (from month 8–9)Часть IV. Работа и рост (с 8–9-го месяца) live

  • Interviews: coding, system design, behavioral
  • First 12–24 months on the job
  • Feedback loops: interview gaps re-prioritize learning
  • Senior track: ownership, mentoring
  • Собеседования: кодинг, system design, поведенческое интервью
  • Первые 12–24 месяца на работе
  • Обратная связь: пробелы с интервью расставляют приоритеты учёбы
  • Трек к senior: владение зоной, менторство

▸ Part V. Highload System Design (10k+ RPS), Outbox & Stateful RunbooksЧасть V. Highload System Design (10k+ RPS), паттерн Outbox и траблшутинг БД live

  • Edge-to-Core architecture for 10,000+ RPS: GeoDNS, CDN/WAF, L4/L7 balancers, and 3-AZ stateless pods
  • Cache-Aside in Redis/Valkey with jittered TTLs and singleflight stampede protection
  • Transactional Outbox pattern for atomic PostgreSQL writes and Kafka event publishing
  • High-availability PostgreSQL (CloudNativePG, PgBouncer transaction pooling, WAL-G S3 PITR)
  • Explicit RTO (< 30s) and RPO (0 lost transactions) engineering and lock_timeout migration hygiene
  • Архитектура Edge-to-Core на 10 000+ RPS: GeoDNS, CDN/WAF, L4/L7 балансировка и stateless-поды в 3 AZ
  • Кэширование Cache-Aside в Redis/Valkey с разбросом TTL (jitter) и защитой от пробоя кэша
  • Паттерн Transactional Outbox для атомарной записи в PostgreSQL и публикации событий в Kafka
  • Отказоустойчивый PostgreSQL (CloudNativePG, пулер PgBouncer в режиме transaction, PITR-бэкапы WAL в S3)
  • Расчет целевых показателей RTO (< 30 с) и RPO (0 потерь) и безопасные DDL-миграции с lock_timeout
