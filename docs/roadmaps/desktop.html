  • Enforcing nodeIntegration: false, contextIsolation: true, and sandbox: true on all BrowserWindow instances
  • Exposing narrow, schema-validated asynchronous APIs via contextBridge.exposeInMainWorld and ipcMain.handle
  • Включение жесткой изоляции окна браузера: nodeIntegration: false, contextIsolation: true и песочница sandbox: true
  • Построение узкого типизированного API между интерфейсом и ОС через contextBridge и асинхронные обработчики ipcMain.handle

▸ Stage 2. Local SQLite Storage, Native OS Integration & Auto-UpdatesЭтап 2. Локальное хранилище SQLite, системная интеграция и автообновления live

  • Running embedded SQLite in WAL mode inside the Main process or utility worker thread for instant local search
  • Code signing (macOS Notarization, Windows Authenticode), system tray menus, and differential auto-updates
  • Работа со встроенной базой SQLite в режиме WAL в основном процессе или воркер-потоке без заморозки интерфейса
  • Криптографическая подпись сборок под macOS и Windows, интеграция с системным треем и безопасная доставка автообновлений
