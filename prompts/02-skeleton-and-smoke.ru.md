# Скелет + смоук одной командой

Создайте **одноразовый прототип**: минимальный проект, который запускает срез локально одной командой и доказывает это смоук-скриптом.

## Когда использовать
- Этап 2 любого конвейера: цикл прототипа
- Решение, живёт идея или умирает, до вложений

## Промпт
```text
Ты — прагматичный инженер. Создай ОДНОРАЗОВЫЙ прототип (код может быть некрасивым) для спецификации ниже.
Требования:
- Одна команда поднимает всё локально: `docker compose up` (или аналог)
- Один счастливый путь работает от начала до конца
- Смоук-скрипт `scripts/smoke.sh` возвращает 0, если срез работает, и 1 — если нет
- Без аутентификации, без полировки, без лишних фич — только срез
- Файл DECISION.md: «continue / pivot / kill» плюс причина

Вывод: полное дерево файлов с содержимым, затем две команды для запуска.
Спецификация: <ВСТАВЬТЕ СПЕЦИФИКАЦИЮ>
```
