# Landing Page Pro (Проектирование лендингов)

> Сначала стратегия, потом токены, в конце чек-лист. Один оффер, одна аудитория, одно действие.

## Быстрый старт
```markdown
# Интейк (одним пакетом, без вопросов по одному)
- Действие: пробная регистрация. Оффер: 14 дней команды, без карты.
- ICP: бэкенд-команды, тонущие в flaky E2E. Возражения: цена, цена переезда.
- Доказательства: 3 логотипа, 2 отзыва, аптайм 99.98%.
- Трафик: поиск. Тон: деловой. Мобильные: да.
```

```bash
# каркас, затем стройка по секциям (не переписывай всю страницу за итерацию)
mkdir -p landing/{sections,assets}
```

## Когда использовать
- Новые маркетинговые страницы и лендинги с нуля
- Хиро-блоки, тарифные секции, FAQ, финальные CTA
- Ревью конверсионных текстов и аудит редизайна
- Любой UI, где каждое визуальное значение идёт из токенов, а не из вкуса

## Лучшие практики

### Стратегия раньше визуала
- Сначала аргумент страницы, потом цвета, шрифты и анимации.
- Один главный CTA. Никаких конкурирующих CTA над фолдом.
- Сообщение под источник трафика: дублируй заголовок объявления в хиро.
- Сначала выгоды, потом фичи. Конкретика вместо vague-глаголов.

### Интейк одним пакетом
- Спрашивай только недостающее, всё одним сообщением.
- Если ответа нет, зафиксируй по одному допущению на пробел и иди дальше. Не стопорь стройку.
- Обязательно: действие, оффер, ICP, топ-3 возражения, источник трафика, доказательства, тон.

### Выбор раскладки
- Выбери ровно один тип и запиши почему:
  - Классика с хиро: продукт понятен со скриншота.
  - Длинная история: нужно учить и снимать скепсис.
  - Минималка: горячий трафик или короткий оффер.
  - Сравнение: в интентах есть альтернативы.
- Порядок стройки: хиро, выгоды, как работает, доказательства, FAQ, финальный CTA.

### Копирайтинг
- Формулы заголовков: "{Результат} без {боли}", "{Категория} для {аудитории}".
- CTA это глагол плюс выгода. Никогда "Узнать больше" или "Отправить".
- Буллеты выгод: жирная выгода, потом доказательство. Бан слов: revolutionize,
  supercharge, cutting edge, effortless, world class. Пиши просто, что делает продукт.
- Заголовки и кнопки с заглавной только первой буквы.

### Визуальные токены
- Один шрифт на сайт. Жирность не выше bold, никакого italic в UI.
- Каждый кегль в шаг шкалы. Округляй вниз, никогда вверх.
- Отступы только из таблицы токенов. Кнопки: 8px по вертикали, 12px по горизонтали.
- Вложенный радиус: внутренний равен внешнему минус зазор, только если зазор меньше 32px и итог больше 2.
- Рамки либо вокруг всей карточки, либо никак. Фоны плоские, без градиентов,
  кроме текстового градиента хиро.
- Одна кривая моушна, 500ms на раскладку, 300ms на ховер. Анимируй только
  transform и opacity. Уважай prefers-reduced-motion.
- Иконки из одного сета (например Phosphor или Lucide). Никогда эмодзи вместо иконок.

### Двуязычные страницы
- Шрифт обязан поддерживать кириллицу (Manrope и Poppins подходят, Geist нет).
- Переводи смысл, а не слова. Цифры, бренды и строки кода оставь без изменений.
- Русские заголовки с заглавной только первой буквы. Проверяй переносы строк в обоих языках.

## Примеры
```markdown
# Структура страницы (классика с хиро, тип A)
1. Хиро: заголовок, подзаголовок, CTA, полоса доказательств, мокап продукта
2. Выгоды x4, через результат
3. Как работает, 3 шага
4. Раскрывающийся таглайн, 2+ строки, слова подсвечиваются при скролле
5. Полоса метрик рядом с тезисами, которые они подтверждают
6. FAQ x6, возражения отдельной секцией
7. Финальный CTA, такой же как верхний
```

```markdown
# Хиро-копи (сначала выгода, конкретно)
Заголовок: "Сократи недельную отчётность с 4 часов до 15 минут"
Подзаголовок: "Acme Reports сводит данные в один дашборд, который читает команда."
CTA: "Начать пробный период" / Доказательство: "4.9/5 от 2,300 команд"
```

```html
<!-- Вложенный радиус: внешний 16px, паддинг 8px, внутренний 8px -->
<div class="rounded-2xl border border-white/10 bg-[#181818] p-2">
  <div class="rounded-lg bg-black p-6">...</div>
</div>
```

```css
/* Моушн: одна базовая кривая, только transform и opacity */
.reveal { opacity: 0; transform: translateY(32px); }
.reveal.in {
  opacity: 1; transform: none;
  transition: opacity 700ms cubic-bezier(0.22,1,0.36,1),
              transform 700ms cubic-bezier(0.22,1,0.36,1);
}
@media (prefers-reduced-motion: reduce) {
  .reveal { opacity: 1; transform: none; transition: opacity 200ms; }
}
```

## Пошаговое руководство
1. Проведи пакетный интейк. Зафиксируй допущения, не стопорься.
2. Напиши структуру страницы и хиро-копи до любого кода.
3. Выбери один тип раскладки и запиши почему.
4. Набросай конверсионный копирайтинг: заголовок, подзаголовок, CTA, выгоды, FAQ.
5. Зафиксируй токены: шрифт, шаги шкалы, таблицу отступов, радиусы, кривую моушна.
6. Строй по секциям в порядке стройки. Ревьювь диффы посекционно.
7. Добавь состояния каждому интерактиву: hover, active, focus, loading, empty, error.
8. Прогони чек-лист Валидации, почини, потом ship.

## Валидация
1. Один оффер, одна аудитория, одно главное действие; нет конкурирующих CTA над фолдом
2. Каждый кегль в шаге шкалы, каждый отступ из таблицы токенов
3. У каждого интерактива есть hover, active, focus, loading, empty, error
4. Контраст 4.5:1, видимый фокус, нет мёртвых ссылок, есть skip-ссылка
5. Title, meta-описание, og-теги, favicon, alt-тексты, семантические ландмарки

## Устранение неполадок
- Generic-вид: жёстко держи таблицы токенов, запрети ad-hoc значения.
- Слабый копирайтинг: замени прилагательные цифрами и доказательствами рядом с тезисами.
- Захламлённое хиро: один CTA, один сигнал доверия, ширина заголовка около 680px.
- Тормоза скролла: IntersectionObserver один раз на секцию, никаких сырых scroll-лисенеров.
- Расползание скоупа: новые хотелки идут в v2, а не в текущий проход.
