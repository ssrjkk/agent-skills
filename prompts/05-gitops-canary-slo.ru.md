# GitOps-доставка + канарейка + SLO

Превратите «размещено» в «эксплуатируется»: декларативная доставка, прогрессивный выкат, SLO с бюджетом ошибок и ночной плейбук.

## Когда использовать
- Этап 5 любого конвейера, когда MVP стабилен под нагрузкой

## Промпт
```text
Ты — платформенный инженер. Сделай этот MVP эксплуатируемым:
1. GitOps: структура репозитория (ApplicationSet), управляющая кластером; состояние кластера == состояние репо
2. Канарейка: прогрессивный выкат с автооткатом при регрессии метрик ошибок; включи учение отката
3. SLO: один пользовательский SLI, цель, бюджет ошибок и алерт выгорания
4. Плейбук: ночной чек-лист (симптом -> команда диагностики -> действие -> проверка), применённый хотя бы раз
Вывод: дерево репо, манифест выката, определение SLO, плейбук.
Стек: <СТЕК И КЛАСТЕР>
```
